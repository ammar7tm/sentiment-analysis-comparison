# Sentiment Analysis: Traditional ML vs DistilBERT

## Description
This project compares traditional machine learning models and a transformer-based model for sentiment analysis using the IMDb dataset.

Models used:
- Logistic Regression
- Linear SVM
- DistilBERT

## Features
- TF-IDF vectorization
- Transformer fine-tuning
- Evaluation using accuracy, precision, recall, F1-score
- Error rate comparison
- Confusion matrices
- Performance vs computational cost analysis

## Dataset
IMDb dataset from Hugging Face.

## Requirements
- Python 3
- datasets
- transformers
- scikit-learn
- pandas
- numpy
- matplotlib
- torch

## How to Run
1. Open notebook in Google Colab
2. Run all cells
3. GPU recommended for DistilBERT
